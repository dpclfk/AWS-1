sequeize 사용중
foreignKey 의경우
targetKey,sourceKey : "id"
onUpdate: "cascade"
onDelete: "set null"
가 디폴트 값으로 설정되어있음

    await UserInfo.findAll({ //findOne 일경우 where에서 맨 위값 하나만 가져옴, findAll일경우 where에서 가진값 전체를 가져옴
      where: { address: "서울시" },
      attributes: ["address", "age"], // 이렇게 서울시를 가진유저중에 주소랑 나이만 가져올수있음
      include: [
        {
          attributes: ["pw"],
          model: UserCrypto,
          include: [
            {
              attributes: ["age"],
              model: UserInfo,
            },
          ],
        },
      ],
    })

include안에값을 sequelize.fn으로 카운터 하려면
상위테이블에서 그룹화(하나만 있는값)을 해준다.

ex)게시글에서 추천수를 가지고 오려면
findOne(Board)안에서 include [{model:BoardLike}] 가있다면
Board 테이블에서
attributes: [[sequelize.fn("count", sequelize.col("BoardLikes.id")), "like"],]
를 해준뒤 { model: BoardLike, attributes: [] }, 로 숫자만 가지고오게한다
Board에서 group :[id] (그룹은 숫자로 된거만 가능)
만약 컬럼이 여러개인데 그중 한개값만 찾아야한다면 include 테이블에서 where로 찾으려는값만 가져오면된다.
