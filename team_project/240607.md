### 플로우 차트

게시판 홈페이지

- 채널 이동
  - 채널명 클릭 -> 채널 이동 URL 변경
- 로그인 이동
  - 유저 아이콘 클릭 -> 로그인 페이지 이동 URL 변경
- 채널 검색
  - 검색어 입력 -> 입력된 검색어 기준으로 채널명 조회
    - -> Enter 입력 -> 종합 속보 페이지로 이동, 검색어로 필터링
    - -> 조회된 채널명 클릭 -> 해당 채널로 이동

회원가입

- 홈페이지 진입 -> 유저 아이콘 클릭 -> 로그인 페이지 이동 -> 계정 만들기 클릭 -> 회원가입 페이지 이동 -> 메일 주소 입력
  - -> 입력된 내용에 대해 메일형식 확인
    - yes -> 에러출력 -> 회원가입 페이지 이동으로 돌아감
    - no -> 체크표시 출력 -> 계정 만들기 클릭 -> 회원가입 형식에 맞는가? (약관 동의, 메일형식)
      - -> yes -> 메일 전송
      - -> no -> 에러출력 -> 회원가입 페이지 이동으로 돌아감

메일을 통한 회원가입 진행

- 메일로 온 URL 클릭 -> 회원 정보 입력 페이지 이동 -> 사용자 입력 -> 입력된 내용에 대해 형식 확인
  - yes -> 체크 출력 -> 계정 만들기 클릭 -> 입력된 내용에 대해 형식 확인
    - yes -> 계정 생성에 대해 서버에 요청 -> 계정 생성 확인
      - yes -> 완료 메세지 - 로그인 페이지 이동
      - no -> 에러 출력
    - no -> 에러 출력
  - no -> 에러 출력

사옹자 입력에 대한 예외처리

- 사용자 입력
- 입력 형식(조건)
- 조건을 기준으로 형식 확인
  - yes -> result: true
  - no -> result: false, code: 코드번호, msg: "이유"

계정 생성

- 계정 생성 요청 받음 -> 계정 데이터 확인
  - yes -> DB에 계정 정보 조회 요청 -> 계정 유무
    - yes -> 에러 메세지 응답
    - no -> DB에 계정 데이터 저장 요청 -> 데이터 정상 저장 완료
      - -> yes -> 로그인 페이지로 redirect 응답
      - -> no -> 에러 메세지 응답
  - no -> 에러 메세지 응답
