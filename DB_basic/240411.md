| bigint    | 8bytes | -9223372036854775808 | 9223372036854775807 | (2 \*\* 8 \*\* 8)            |

### fixed-point number

- 소수점이 정해진 실수
- DECIMAL(M,D)
  - M : 숫자의 총 길이
  - D : 소수점의 위치

```sql
DECIMAL(10,5);
  - 12345671 >> 123.45671
  - 1234567113 >> 12345.67113
  - 123456711397746 >> 12345.67114
```

### floating-poing number

- 소수점이 정해지지 않은 실수
- FLOAT(P) : P는 정밀도 0~24까지의 정밀도는 float, 25~53 까지의 정밀도는 double
- FLOAT(M,D) : -3.402823e+38 ~ 3.402823e+38 << 4byte
- DOUBLE(M,D) : -1.76769e+308 ~ 1.76769e+308 << 8byte

### bit-value

- BIT(M) : 최대 64의 길이를 가질 수 있다.

```sql
CREATE TEBLE test (
  'id' TINYINT UNSIGNED,
  'tall' FLOAT(5,2),
  'weight' DECIMAL(5,2),
)
```

### CHAR

- character의 약자
- string의 한글자 << char가 모여서 string가 된다 string == char[]
- a, b, c, ㄱ, ㄴ, ㄷ, 가, 나, 다, ㅏ, ㅓ, ㅑ, 1, 2, 3, ...
- CHAR(M) : 최대 255자

### VARCHAR

- variable character
- char랑 사용하기에는 크게 다를게 없다.
- VARCHAR(M) : 최대 65535자

### CHAR VS VARCHAR

- CHAR(10) << 10자를 무조건 넣게된다.
- VARCHAR(10) << 넣은것만 들어간다.

### BLOB VS TEXT

- BLOB : Binary Large Object
  - Binary를 저장하기 위한(bit) 타입
  - TINYBLOB(256byte), BLOB(64kb), MEDIUMBLOB(8mb), LONGBLOB(4gb)
- TEXT : string 저장하기 위한 타입(최대 용량은 위와 같음)
  - TINYTEXT, TEXT, MEDIUMTEXT, LONGTEXT

### ENUM

- enumeration : 열거형
- data ENUM('data1', 'data2')
  - data = 'data1' || 'data2'
- 미리 설정한 값만을 하나만 넣을 수 있다.

```sql
create table text (
gender ENUM('man', 'woman' )
);

```

### SET

- data SET('data1','data2')
  - data = 'data1, data2'
- 미리 설정한 값만을 넣을 수 있다. (개수 무관)

### DATE, DATETIME, TIMESTAMP

- DATE : YYYY-MM-DD
- DATETIME : YYYY-MM-DD HH:MM:SS
- TIMESTAMP : number(UTC)

### TIME

- HH:MM:SS || HHH:MM:SS

## Constraint

- 재약조건(강제)

## NOT LULL

- 널이 아니다. 값이 항상 들어가야한다.

## UNSINED

- 음수가 없다.

## UNIQUE

- 유일한, 값이 중복될수 없다.
