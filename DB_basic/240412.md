# DML

- Data Manipulation Language
- 데이터를 직접적으로 다루는 언어이다.

# 현재 사용중인 데이터베이스, 유저

SELECT DATABASE();
SELECT USER();

## insert

```sql
INSERT INTO test VALUES (1, '2024-04-12 09:00:00', '이름', 34, '닉네임');

INSERT INTO test (id, name, nick) VALUES (4, '이름', '2닉네임2');
```

## update

```sql
UPDATE test SET created_at='2024-04-12 09:12:00' WHERE id=2;

```

## delete

```sql
DELETE FROM test WHERE id=1;
```

## select

```sql
select * from test;
select id,nick FROM test WHERE id=2;
```

- DML에 포함하지 않고 DQL, Data Query Language에 포함시키는 경우도 있다.

# PRIMARY KEY

- 기본적인
- 데이터를 다룰 때 -> 검색하거나 정렬하거나

```sql
CREATE TABLE aws_student (
  id TINYINT UNSIGNED PRIMARY KEY AUTO_INCREMENT,
  name VARCHAR(5) NOT NULL,
  age TINYINT UNSIGNED NOT NULL,
  birth VARCHAR(5),
  address VARCHAR(20) NOT NULL,
  phone VARCHAR(13) NOT NULL UNIQUE,
  gender ENUM('M','F') NOT NULL,
  registed_at DATETIME DEFAULT NOW()
)
```
